## HTML
<!DOCTYPE HTML> - паспорт документа. Говорит браузеру: "это HTML5".
<html lang="ru"> - корень документа. lang="ru" - контент на русском.
<head> - служебная информация (название вкладки, CSS, meta).
<link rel="stylesheet" href="style.css"> - подключение внешнего CSS.
<title> - название вкладки в браузере.
<body> - все, что видно пользователю.
<meta charset="UTF-8"> - Атрибут, который указывает кодировку страницы. UTF-8 поддерживает все языки: Русский, английский, китайский, и даже эмодзи (не язык, но все же).
Зачем: без него русский текст может отображаться кракозябрами.
Где ставить: первым в <head>.
<meta name="viewport" content="width=device-width, initial-scale=1.0"> - Атрибут, который говорит браузеру, как масштабировать страницу на мобильных
<nav> - Навигация. Блок со ссылками для перехода по сайту.
<em> - Не просто курсив, но еще и с акцентом.


## Семантические теги
<header> - шапка сайта (заголовок, логотип, меню).
<main> - основное содержимое страницы.
<section> - тематический блок (например, "Друзья").
<article> - самостоятельная единица (карточка друга).
<footer> - самый низ сайта (подвал).
<div> - просто коробка, но все же имеет какой то смысл.


## Текстовые теги
<h1> - главный заголовок на странице, пример: "Hello", самый главный текст на странице
<h2> - подзаголовок, пример: под верхним хелло(<h1>) будет этот h2, допустим (Меня зовут Iron).
<p> - абзац текста, пример после (Меня зовут Iron) идет рассказ обо мне, кто я, сколько лет.
<strong> - важный текст (жирный).
<em> - акцент (курсив).


## Атрибуты
class="..." - класс для CSS и JS. Для более легкой измены чего либо (текста,цвета).
id="..." - уникальный идентификатор. Применяется лишь один раз, и пишется через "#".
data-id="1" - свой атрибут, читается в JS как dataset.id.
alt="..." - текст, если картинка не загрузилась. Частый случай
src="..." - путь к файлу, допустим <script src="script.js"></script> (Подключение JS.).
href="..." - ссылка. Часто используют чтобы сделать многостраничный сайт.


## CSS

## База
- margin - внешний отступ (расстояние до соседних элементов).
- padding - внутренний отступ (расстояние от границы до контента).
- border - границы элемента (рамка вокруг).
Пример: border: 1px solid #222;
- border-radius - Округление углов
Пример: border-radius: 15px;
background-color - Цвет фона. Часто используют либо в изменении фона сайта, либо в изменении фона в <div></div>
color - цвет текста. Часто используют чтобы изменять текст например в <h1>,<h2>,<p>, и даже в <a>.
width - ширина. Можно допустим изменить ширину <div> или <article>, довольно полезно.
Минус: фиксированная, на телефоне может вылезти.
height - высота элемента.
Пример: height: 250px;
max-width - максимальная ширина.
Пример: max-width: 1200px;
Плюс: элемент не шире 1200px, но на телефоне сжимается.
Используй с width: 100% и margin 0 auto.
font-size - размер шрифта. Пример:
h1 {
    font-size: 25px;
}
font-family - изменение шрифта на сайте.
text-align - выравнивание текста. Вот допустим, заголовок( <h1> ) сейчас слева, а с помощью text-align он выравнивается в центр.
line-height - межстрочный интервал
display - режим отображения (block, flex, grid).
- block - блочный (элемент на всю ширину, друг под другом).
- flex - flex-режим (элементы в линию).
- grid - grid-режим (элементы в сетку).
- none - скрыть элемент.
- inline - строчный (как текст).


## Flexbox
display: flex - включает flex - режим, все элементы становятся в линию
justify-content: flex-start - Выравнивание по горизонтали. Часто используется, но данный термин имеет не одно понятие, а также:
- flex-start - Элементы становятся слева ( в начале оси ).
- flex-end - Элементы становятся справа ( в конце оси ).
- center - Элементы становятся по центру.
- space-between - Так сказать по разным сторонам. Первый слева, последний справа, между ними равные промежутки.
- space-around - вокруг каждого элемента равные промежутки. Более менее схоже с space-between.
- space-evenly - между всеми элементами одинаковые промежутки.
align-items - выравнивание по вертикали:
- center - по центру
- flex-start - по вверху ( текст будет вверху )
- flex-end - внизу ( не в самом подвале как <footer>).
flex-wrap - перенос на новую строку:
wrap - переносить
nowrap - не переносить (по умолчанию).
space-evenly - между всеми элементами одинаковые промежутки.


## Grid
display: grid - включает grid - режим (элементы в сетку).
grid-template-columns - задает колонки.
Пример: repeat(auto-fit, minmax(280px, 1fr));
gap - расстояние между соседями в комнате. Если ты один - расстояния нет.
.cards-row {
    display: grid;
    grid-template-colums: repeat(auto-fit, minmax(280px, 1fr));
    gap: 25px;
}



## Картинки

- object-fit: cover - картинка заполняет блок, обрезая лишнее.
- object-fit: contain - вписывает целиком, оставляет пустоты.
- object-fit: fill - растягивается, но искажается. Главный минус.
- object-fit: none - оригинальный размер. Без масштабирования.



## Анимации
transition - плавный переход между состояниями.
Пример: transition: transform 0.3s ease;
Пример с двумя свойствами: transition: transform 0.3s ease, box-shadow 0.3s ease;
transform: translateY(-8px) - сдвиг элемента вверх при наведении.
transform: scale(1.02) - увеличение элемента на 2%.
box-shadow - тень.
Пример: box-shadow: 0 10px 30px rgba(0, 0, 0, 0.3);
Разбор:
- 0 - Смещение по X ( вправо ).
- 10px - смещение по Y ( Вниз ).
- 30px - размытие.
- rgba (0, 0, 0, 0.3) - цвет с прозрачностью.

## JavaScript

### Переменные
const - Главное правило, изменить нельзя
let - В отличие от const, let можно изменить свободно
var - Сейчас не используется, старый способ переменной


### Поиск элементов
- document.querySelector('.class') - Найти первый элемент по CSS - селектору.
- document.querySelectorAll('.class') - В отличии от обычного "querySelector", данный вид ищет не первый элемент, а ВСЕ, пример:
- const buttons = document.querySelectorAll('.btn-details');
- document.getElementById('id') - Наверно самый легкий поиск в данной сфере, т.к в нем нет ничего сложного. Пример:
- const byeButton = document.getElementById('byeButton');
- addEventListener('click', function() { . . . }) - Повесить обработчик на событие, или же действие. Как работает? В нашем коде имеется 'click', что говорит "Когда произойдет действие, произойдет событие".
- element.innerHTML - Вставить HTML внутрь элемента. То есть, допустим, у нас есть изначальный <p>, но чтобы заменить наш текущий <p> на другой, для этого и нужен innerHTML
- element.textContent - Вставить текст внутрь элемента, без HTML.
- element.classList.add('open') - Добавить класс элементу. Довольно кратко и понятно. Пример:
details.classList.add('open');
details.classList.toggle('open') - Переключить класс: если есть - удалит, если нет - добавит. Пример:
details.classList.toggle('open');
// Первый клик: класс добавлен <div class="details open">
details.classList.toggle('open');
// Второй клик: класс удален. <div class="details">
element.classList.remove('open') - удалить класс.
element.classList.contains('open') - проверить наличие (true/false).

element.closest('.class') - Найти ближайшего родителя по селектору.
element.dataset.id - Чтение data- атрибутов
if/else - Условие. Если - то, иначе - другое.
