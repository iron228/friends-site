# 🚀 Моя шпаргалка по вебу

## 📌 HTML

### Структура страницы
- `<!DOCTYPE html>` — говорит браузеру, что это HTML5
- `<html lang="ru">` — корень, язык русский
- `<head>` — мета-информация (title, css, meta)
- `<body>` — видимый контент

### Семантические теги
- `<header>` — шапка
- `<main>` — основное содержимое
- `<section>` — тематический блок
- `<article>` — самостоятельная единица (карточка, пост)
- `<footer>` — подвал
- `<div>` — просто коробка (без смысла)

### Атрибуты
- `class="..."` — класс для CSS и JS
- `id="..."` — уникальный идентификатор
- `data-id="1"` — свой атрибут, читается в JS как `dataset.id`
- `alt="..."` — текст, если картинка не загрузилась

## 🎨 CSS

### База
- `margin` — внешний отступ
- `padding` — внутренний отступ
- `border` — граница
- `border-radius` — скругление углов
- `background-color` — цвет фона
- `color` — цвет текста

### Flexbox
```css
display: flex;
justify-content: center;  /* по горизонтали */
align-items: center;      /* по вертикали */
gap: 20px;                /* расстояние */
flex-wrap: wrap;          /* перенос на новую строку */
